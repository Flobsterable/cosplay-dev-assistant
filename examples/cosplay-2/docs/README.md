# Документация Cosplay 2

Cosplay 2 — Android/Desktop приложение для просмотра фестивалей с cosplay2.ru.
Пользователь ищет события, фильтрует их по типу, году и месяцу, открывает подробности
и получает уведомления о новых версиях приложения из GitHub Releases.
Это клиент внешнего сервиса; отдельного backend и базы данных фестивалей в проекте нет.

## Основные технологии

Kotlin Multiplatform, Compose Multiplatform, Material 3, Ktor Client,
kotlinx.serialization и kotlinx.datetime. Код разделён на app shell, core, data и feature.
Android использует движок Ktor OkHttp, Desktop — CIO.

## Как читать документацию

Начните с architecture.md, затем изучите нужный сценарий в feature-flows.md.
Контракты ответов и назначение полей приведены в festival-api.md и data-model.md.
Пути в документации записаны относительно корня Git-репозитория.
Версии библиотек и Android SDK задаются в gradle/libs.versions.toml.

Документы описывают реализованное поведение, а не план будущего развития.
Описание внешнего API основано на клиентском коде и не является официальной спецификацией cosplay2.ru.
При изменении API, моделей, навигации или релизного процесса обновляйте соответствующие документы.
